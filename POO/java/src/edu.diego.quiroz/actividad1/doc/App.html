Clase App

Paquete: edu.diego.quiroz.actividad1.process

Hereda de: javafx.application.Application

Descripción

Clase principal de la aplicación TecmiNuevos. Punto de entrada de la aplicación JavaFX. Se encarga de inicializar el sistema y mostrar la interfaz de usuario.

Métodos

public void start(Stage stage)
Método principal de inicio de JavaFX. Muestra primero el diálogo de selección de idioma y luego la ventana principal.

Parámetros:
  • stage - Escenario principal de JavaFX
public static void main(String[] args)
Punto de entrada de la aplicación. Lanza la aplicación JavaFX.

Parámetros:
  • args - Argumentos de línea de comandos

Flujo de Ejecución

  1. La aplicación inicia mostrando el diálogo de selección de idioma
  2. Si el usuario selecciona un idioma, se carga el gestor de idiomas
  3. Se muestra la ventana principal con el catálogo de vehículos
  4. Si el usuario cierra el diálogo sin seleccionar, la aplicación se cierra
