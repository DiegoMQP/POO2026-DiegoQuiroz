Clase VentanaPrincipal

Paquete: edu.diego.quiroz.actividad1.ui

Descripción

Ventana principal del sistema de ventas. Muestra el catálogo de vehículos disponibles y permite al usuario añadirlos al carrito de compras. Incluye funcionalidades de búsqueda, filtrado y gestión del carrito.

Componentes Principales

  • Catálogo de vehículos con tarjetas visuales
  • Panel de carrito de compras
  • Calculadora de totales
  • Generación de tickets PDF

Métodos Principales

public VentanaPrincipal(Stage stage)
Constructor que inicializa la ventana principal.

Parámetros:
  • stage - Escenario de JavaFX para mostrar la ventana
public void mostrar()
Muestra la ventana principal con todos sus componentes.
private void agregarAlCarrito(Vehiculo vehiculo)
Añade un vehículo al carrito de compras y abre el diálogo de extras si está disponible.

Parámetros:
  • vehiculo - Vehículo a añadir al carrito
private void actualizarCarrito()
Actualiza la visualización del carrito y recalcula el total.
private void finalizarCompra()
Finaliza la compra, genera el ticket PDF y reinicia el sistema.

Funcionalidades

  • Visualización de catálogo con imágenes y detalles
  • Añadir vehículos al carrito
  • Selección de extras y accesorios
  • Cálculo de totales con IVA
  • Generación de tickets PDF
  • Interfaz multiidioma
