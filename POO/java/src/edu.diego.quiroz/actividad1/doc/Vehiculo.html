Clase Vehiculo

Paquete: edu.diego.quiroz.actividad1.process

Tipo: Clase abstracta

Descripción

Clase abstracta que representa un vehículo genérico en el sistema. Define los atributos y métodos comunes para todos los tipos de vehículos.

Atributos

protected String marca - Marca del vehículo
protected String modelo - Modelo del vehículo
protected int año - Año de fabricación
protected String color - Color del vehículo
protected String motor - Tipo de motor
protected String transmision - Tipo de transmisión
protected String combustible - Tipo de combustible
protected int pasajeros - Capacidad de pasajeros
protected double precio - Precio del vehículo
protected String tipo - Tipo de vehículo (Nuevo/Seminuevo)
protected String urlImagen - URL de la imagen del vehículo

Métodos Principales

public String getMarca()
Retorna la marca del vehículo.
public String getModelo()
Retorna el modelo del vehículo.
public double getPrecio()
Retorna el precio del vehículo.
public String getTipo()
Retorna el tipo de vehículo.
public abstract String getDescripcionCompleta()
Método abstracto que debe ser implementado por las subclases para obtener una descripción completa del vehículo.
